# Font assets

- `source/` — editable glyph-text sources;
- `binary/` — generated/legacy bitmap font binaries;
- `header/` — generated headers and preview bitmaps;
- `ttf/` — source TrueType fonts used by legacy conversion workflows.

The converter/editor source itself lives under `src/tools/fonts/` and its documentation under `docs/development/fonts/`.
