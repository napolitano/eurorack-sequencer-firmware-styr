# LFO Track — Development Notes

User-facing operation is documented in the [LFO Track manual](../../manual/features/lfo/README.md). This file is limited to implementation-level references.

The LFO track is represented by `src/sequencer/model/LfoTrack.{h,cpp}`, executed by `src/sequencer/engine/LfoTrackEngine.{h,cpp}` and rendered through `src/sequencer/ui/pages/LfoPage.{h,cpp}` plus `src/sequencer/ui/painters/LfoPainter.{h,cpp}`. `Track::TrackMode::Lfo` is serialized as track mode value 3, and LFO persistence is introduced by project format version 32.

Automated user-manual captures for Sync, Free and Shift-layer states are generated by `src/simulator/tools/manual_screenshots.cpp`; see the [documentation screenshot pipeline](../documentation/README.md).
