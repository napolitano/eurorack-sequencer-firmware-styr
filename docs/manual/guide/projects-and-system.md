# Projects, Maintenance, and System Tasks

## Project management

From [Project](../screens/global/project.md), `SHIFT` + `PAGE` opens actions:

- **Init**: clear project content
- **Load**
- **Save**
- **Save As**

Save regularly when building songs or performance states.

## Monitoring and diagnostics

Use [Monitor](../screens/monitor/README.md) pages to inspect:

- CV input levels
- CV output behavior
- MIDI event flow
- runtime stats

These views are useful when troubleshooting routing, input filtering, or expected output activity.

## Calibration

Use [System Calibration](../screens/system/system-calibration.md) with accurate measurement tools when output voltage must be corrected per channel.

## Utilities and backups

[System Utilities](../screens/system/system-utilities.md) includes maintenance tasks such as SD formatting.
Treat these as destructive operations and back up first.

## Firmware update

Use [System Update](../screens/system/system-update.md) to enter bootloader update flow, then follow the full SD-card procedure in [README_FIRMWARE_UPDATE.md](../../../README_FIRMWARE_UPDATE.md).

## Advanced settings

Some firmware versions include an Advanced page in System settings. Current visible rows include **Enhanced UI** and **Language**.
