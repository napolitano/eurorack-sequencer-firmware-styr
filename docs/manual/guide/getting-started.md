# Getting Started: First Sequence

This workflow gets a basic pattern running quickly.

## 1) Set tempo and project basics

1. Open [Project](../screens/global/project.md).
2. Set **Tempo** and (if needed) **Scale** / **Root Note**.
3. If you plan to record, confirm input settings in the recording chapter.

## 2) Select a Note Track

1. Press a track key (`T1`…`T8`) to select the target track.
2. Open [Track](../screens/note/note-track.md) and confirm it is a Note Track.

## 3) Define the loop length

1. Open [Note Sequence](../screens/note/note-sequence.md).
2. Set **First Step**, **Last Step**, and **Divisor**.
3. Start with a short loop (for example, 16 steps) while learning.

## 4) Enter steps

1. Open [Note Steps](../screens/note/note-steps.md).
2. Use step keys to place gates/notes.
3. Use function keys to move between layer groups (gate, retrigger, length, note, condition).

## 5) Start playback

- Press `PLAY` to run transport.
- Use `TEMP` hold for quick tempo adjustment from [Tempo](../screens/global/tempo.md).

## 6) Save the project

1. Return to [Project](../screens/global/project.md).
2. Open the context menu (`SHIFT` + `PAGE`) and use **Save** or **Save As**.
