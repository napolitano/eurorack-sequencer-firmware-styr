# LFO — Frequency

![LFO — Frequency](../../assets/lfo-frequency.png)

## Function

Sets free-running LFO frequency.

## Access

In Free mode, press the rate function (`F2`).

## Operation

Frequency is stored in 0.01 Hz steps and is limited to 0.00–20.00 Hz.
