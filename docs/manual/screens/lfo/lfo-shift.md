# LFO — Shift Layer

![LFO — Shift Layer](../../assets/lfo-shift.png)

## Function

Displays the LFO’s secondary function-key layer.

## Access

Hold `SHIFT` on the LFO page.

## Operation

The secondary layer exposes Pulse Width for Square, Clip, and Nudge where the current mode/waveform supports it.
