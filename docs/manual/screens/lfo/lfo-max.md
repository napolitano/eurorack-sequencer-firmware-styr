# LFO — Max

![LFO — Max](../../assets/lfo-max.png)

## Function

Sets the upper LFO output limit.

## Access

On the LFO page, press `F5` / **Max**.

## Operation

The value is stored in 0.01 V units and supports -5.00 V through +5.00 V. Documentation captures use +5.00 V.
