# LFO — Sync Overview

![LFO — Sync Overview](../../assets/lfo-sync.png)

## Function

Shows a tempo/step-synchronised LFO with a deliberately full-scale bipolar output range.

## Access

Select an LFO track and open `PAGE` + `S1` (`STEPS`).

## Operation

The documentation fixture forces **Min = -5.00 V** and **Max = +5.00 V** in both base and routed value lanes so the waveform always uses the full vertical display range.
