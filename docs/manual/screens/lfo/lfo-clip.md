# LFO — Clip

![LFO — Clip](../../assets/lfo-clip.png)

## Function

Enables or disables clipping of the LFO output at the configured range.

## Access

Hold `SHIFT` and select **Clip** on the LFO page.

## Operation

Turn the encoder to switch the Boolean state.
