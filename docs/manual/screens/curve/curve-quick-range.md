# Curve Quick Edit — Range

![Curve Quick Edit — Range](../../assets/curve-quick-range.png)

## Function

Selects the Curve sequence voltage range.

## Access

From Curve Steps, hold `PAGE` + `S14`.

## Operation

Keep the chord active and turn the encoder to change the value without leaving the step editor.
