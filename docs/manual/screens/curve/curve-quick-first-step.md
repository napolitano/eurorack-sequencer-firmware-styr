# Curve Quick Edit — First Step

![Curve Quick Edit — First Step](../../assets/curve-quick-first-step.png)

## Function

Sets the first step of the active playback range.

## Access

From Curve Steps, hold `PAGE` + `S9`.

## Operation

Keep the chord active and turn the encoder to change the value without leaving the step editor.
