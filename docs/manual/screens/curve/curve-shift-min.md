# Curve Steps — Shift + Min

![Curve Steps — Shift + Min](../../assets/curve-shift-min.png)

## Function

Jumps directly to the primary **Min** layer instead of cycling within its function group.

## Access

On Curve Steps, hold `SHIFT` and press `F2`.

## Operation

Release `SHIFT` after the layer is selected and continue normal step editing.
