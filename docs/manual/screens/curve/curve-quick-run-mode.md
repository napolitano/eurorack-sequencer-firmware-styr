# Curve Quick Edit — Run Mode

![Curve Quick Edit — Run Mode](../../assets/curve-quick-run-mode.png)

## Function

Changes sequence traversal order.

## Access

From Curve Steps, hold `PAGE` + `S11`.

## Operation

Keep the chord active and turn the encoder to change the value without leaving the step editor.
