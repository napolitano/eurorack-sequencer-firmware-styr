# Monitor — CV In

![Monitor — CV In](../../assets/monitor-cv-in.png)

## Function

Displays the current values observed on the CV inputs.

## Access

Press `PAGE` + `S8` (`MONITOR`) and select CV In.

## Operation

Use this page to verify incoming control voltages and patching.
