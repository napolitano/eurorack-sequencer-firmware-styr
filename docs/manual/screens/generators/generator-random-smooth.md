# Random — Smooth

![Random — Smooth](../../assets/generator-random-smooth.png)

## Function

Repeatedly smooths neighbouring generated values.

## Access

Hold **Smooth** and turn the encoder.

## Operation

Range is 0–10 smoothing iterations.
