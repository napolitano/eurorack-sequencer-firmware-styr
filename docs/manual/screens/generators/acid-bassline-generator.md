# Acid Bassline Generator

![Acid Bassline Generator](../../assets/acid-bassline-generator.png)

## Function

Builds a deterministic acid-oriented Note phrase and previews it before acceptance.

## Access

Confirm **Acid Bassline** in the generator selector.

## Operation

The five parameters are Seed, Root, Length, Density and Legato. The generator modifies several Note-sequence properties as a coherent phrase rather than only filling one scalar layer.
