# Generator Selection — Acid Bassline

![Generator Selection — Acid Bassline](../../assets/generator-select-acid-bassline.png)

## Function

Selects Styr’s Note-sequence Acid Bassline generator.

## Access

From a Note Steps page, open `SHIFT` + `PAGE` → **Generate** and select **Acid Bassline**.

## Operation

Confirm to open the live bassline preview.
