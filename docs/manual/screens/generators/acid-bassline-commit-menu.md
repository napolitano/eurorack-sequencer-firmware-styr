# Acid Bassline — Commit Menu

![Acid Bassline — Commit Menu](../../assets/acid-bassline-commit-menu.png)

## Function

Provides Init, Revert and Commit for the bassline preview.

## Access

While Acid Bassline is open, hold `SHIFT` + `PAGE`.

## Operation

Commit accepts the phrase; Revert restores the sequence that existed before the generator was opened; Init returns the generator parameters to their defaults.
