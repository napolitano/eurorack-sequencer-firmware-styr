# Acid Bassline — Seed

![Acid Bassline — Seed](../../assets/acid-bassline-seed.png)

## Function

Chooses the deterministic phrase seed.

## Access

Hold **Seed** and turn the encoder.

## Operation

Seed range is 0–65535. With the encoder modifier/shift behaviour, the implementation can jump to another generated seed.
