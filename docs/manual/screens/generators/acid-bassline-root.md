# Acid Bassline — Root

![Acid Bassline — Root](../../assets/acid-bassline-root.png)

## Function

Selects the harmonic root used by the generated phrase.

## Access

Hold **Root** and turn the encoder.

## Operation

Root is limited to the 12 chromatic pitch classes C through B.
