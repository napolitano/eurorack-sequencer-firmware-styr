# Acid Bassline — Legato

![Acid Bassline — Legato](../../assets/acid-bassline-legato.png)

## Function

Controls the amount of legato/slide behaviour in the generated phrase.

## Access

Hold **Legato** and turn the encoder.

## Operation

Range is 0–100%. It affects the phrase’s connected/slide character rather than simply changing note count.
