# Routing — Edit Route

![Routing — Edit Route](../../assets/routing-edit.png)

## Function

Shows a route while one of its fields is actively being edited.

## Access

On the Routing page, select a field and press the encoder.

## Operation

Rotate the encoder to change the selected field; press again to leave edit mode.
