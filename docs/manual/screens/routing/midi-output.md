# MIDI Output

![MIDI Output](../../assets/midi-output.png)

## Function

Configures the sequencer’s MIDI output mappings.

## Access

Press `PAGE` + `T4` (`MIDIOUT`).

## Operation

Select the output entry and edit its destination/settings with the list-page encoder workflow.
