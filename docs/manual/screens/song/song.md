# Song

![Song](../../assets/song.png)

## Function

Arranges patterns into a longer chain of song slots.

## Access

Press `PAGE` + `S4` (`SONG`).

## Operation

Edit song slots and their pattern assignments, then use the transport controls to start/stop song playback.
