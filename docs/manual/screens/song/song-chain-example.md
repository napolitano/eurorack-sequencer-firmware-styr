![Song — Chain Example](../../assets/song-chain-example.png)

## Function

Shows a populated song chain rather than the empty/default Song page.

## Access

Create several song slots/pattern entries on the Song page.

## Operation

The example illustrates how multiple pattern selections form a longer arrangement.
