# Note Quick Edit — Root Note

![Note Quick Edit — Root Note](../../assets/note-quick-root-note.png)

## Function

Selects the harmonic root used with the sequence scale.

## Access

From Note Steps, hold `PAGE` + `S15`.

## Operation

Keep the quick-edit chord active and turn the encoder to change the value without leaving the step-edit workflow.
