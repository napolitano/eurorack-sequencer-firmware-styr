# Note Steps — Gate

![Note Steps — Gate](../../assets/note-steps.png)

## Function

Enables or disables the gate for each step.

## Access

Select a Note track, open `PAGE` + `S1` (`STEPS`), then select this layer with the corresponding function key.

## Operation

Press a step key to toggle its gate. Hold one or more steps and turn the encoder for relative multi-step editing where supported.

## Notes

Function keys can group several layers. Repeated presses cycle within a group; `SHIFT` + the function key returns directly to the group’s primary layer.
