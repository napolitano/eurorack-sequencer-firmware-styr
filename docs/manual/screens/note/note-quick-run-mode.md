# Note Quick Edit — Run Mode

![Note Quick Edit — Run Mode](../../assets/note-quick-run-mode.png)

## Function

Changes the order in which the active sequence range is traversed.

## Access

From Note Steps, hold `PAGE` + `S11`.

## Operation

Keep the quick-edit chord active and turn the encoder to change the value without leaving the step-edit workflow.
