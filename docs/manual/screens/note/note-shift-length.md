# Note Steps — Shift + Length

![Note Steps — Shift + Length](../../assets/note-shift-length.png)

## Function

Jumps directly to the primary **Length** layer instead of cycling through the other layers assigned to the same function group.

## Access

On Note Steps, hold `SHIFT` and press `F3`.

## Operation

Release `SHIFT` after the layer is selected; normal step editing then continues on the selected layer.
