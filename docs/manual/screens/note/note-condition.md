# Note Steps — Condition

![Note Steps — Condition](../../assets/note-condition.png)

## Function

Assigns conditional playback rules to steps, allowing short patterns to evolve across fills, previous-step state or loop iterations.

## Access

Select a Note track, open `PAGE` + `S1` (`STEPS`), then select this layer with the corresponding function key.

## Operation

Hold one or more steps and turn the encoder to select a condition.

## Notes

Function keys can group several layers. Repeated presses cycle within a group; `SHIFT` + the function key returns directly to the group’s primary layer.
