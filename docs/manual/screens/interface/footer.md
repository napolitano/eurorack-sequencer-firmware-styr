# Display Footer

![Display Footer](../../assets/footer.png)

## Function

The footer labels the five physical function buttons `F1`…`F5` for the current page and context.

## Operation

Read the footer before using a function key: the same physical key can select a sub-page, cycle a layer group, expose a parameter, or invoke a context action depending on where you are.

On pages with sub-pages, the active function can be highlighted. Holding `SHIFT` can expose an alternate function layer. Holding `SHIFT` + `PAGE` on pages with a context menu replaces the normal labels with the available menu actions.

## Why it matters

The footer is part of Styr’s navigation model rather than decoration. Feature documentation therefore describes function-key actions by both their physical key (`F1`…`F5`) and the label visible in the footer.
