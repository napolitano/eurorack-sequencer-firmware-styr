# Pattern

![Pattern](../../assets/pattern.png)

## Function

Selects which of the 16 patterns are playing and which pattern is being edited.

## Access

Hold `PATT` for temporary access or use the page navigation assigned to Pattern.

## Operation

Press a step key to request/select a pattern. Track buttons can scope a pattern change to selected tracks; the header distinguishes the play pattern from the edit pattern.
