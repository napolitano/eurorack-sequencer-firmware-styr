# Overview

![Overview](../../assets/overview.png)

## Function

Provides a compact status view across the eight tracks so the current project can be assessed without opening each track individually.

## Access

Press `PAGE` + `PREV` to open Overview.

## Operation

Use the track and navigation controls as indicated by the page. The header still identifies the currently selected track and pattern context.
