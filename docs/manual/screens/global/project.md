# Project

![Project](../../assets/project.png)

## Function

Edits project-wide timing/musical/input settings and provides project management actions.

## Access

Press `PAGE` + `T1` (`PROJECT`).

## Operation

List-page editing uses the encoder: select an item, press to enter edit mode, turn to change the value, then press again to exit edit mode.

Main settings include:

- Tempo, Swing, Time Signature, Sync Measure
- Scale and Root Note
- Monitor Mode and Record Mode
- MIDI Input, CV/Gate Input, Curve CV Input

`SHIFT` + `PAGE` opens project actions:

- **Init**
- **Load**
- **Save**
- **Save As**
- **Route** (when routing is supported for the selected row)

Use this page before recording so input filtering and record mode match your intent.
