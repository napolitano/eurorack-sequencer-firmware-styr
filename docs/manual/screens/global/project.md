# Project

![Project](../../assets/project.png)

## Function

Edits project-wide settings and provides project load/save operations.

## Access

Press `PAGE` + `T1` (`PROJECT`).

## Operation

List-page editing uses the encoder: select an item, press the encoder to enter edit mode, rotate to change it, then press again to leave edit mode. `SHIFT` + `PAGE` opens project actions such as Init, Load, Save and Save As.
