# Tempo

![Tempo](../../assets/tempo.png)

## Function

Provides immediate temporary access to the master tempo.

## Access

Hold `TEMP`.

## Operation

Turn the encoder while the temporary Tempo page is visible to adjust tempo. Releasing `TEMP` returns to the previous page.
