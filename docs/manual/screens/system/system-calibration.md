# System — Calibration

![System — Calibration](../../assets/system-calibration.png)

## Function

Displays CV-output calibration values for the eight hardware channels.

## Access

Open System and select Calibration.

## Operation

Select the channel and calibration point, then compare the physical output against an accurate voltmeter before editing the calibration value.
