# System

![System](../../assets/system-confirm.png)

## Function

Provides system-level configuration and access to maintenance functions.

## Access

Press `PAGE` + `T8` (`SYSTEM`).

## Operation

Use the function keys to switch between the available system tabs:

- **Calibration**
- **Advanced Settings**
- **Utilities**
- **Update**

Potentially destructive actions require confirmation. The Calibration tab also exposes **Init**, **Save**, **Backup**, and **Restore** in its settings context menu.
