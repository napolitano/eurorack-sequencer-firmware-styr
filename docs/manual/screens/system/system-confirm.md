# System

![System](../../assets/system-confirm.png)

## Function

Provides system-level configuration and access to maintenance functions.

## Access

Press `PAGE` + `T8` (`SYSTEM`).

## Operation

Use the function keys to switch between available system tabs. Potentially destructive actions require deliberate confirmation.
