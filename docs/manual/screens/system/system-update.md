# System — Update

![System — Update](../../assets/system-update.png)

## Function

Shows the installed firmware version and provides the on-device path into the bootloader for an SD-card firmware update.

## Access

Open System and select Update.

## Operation

With a valid `UPDATE.DAT` in the SD-card root, hold the encoder for about two seconds to reset into the bootloader. The full SD-card update procedure and ST-Link safety notes are in [`README_FIRMWARE_UPDATE.md`](../../../../README_FIRMWARE_UPDATE.md).
