# System — Advanced Settings

![System — Advanced Settings](../../assets/system-advanced.png)

## Function

Shows advanced UI-related settings in one list.

## Access

Open System and select Advanced Settings.

## Operation

The current page shows **Enhanced UI** and **Language** rows as placeholders. In the current firmware state, these rows are visible but not editable from this page.
