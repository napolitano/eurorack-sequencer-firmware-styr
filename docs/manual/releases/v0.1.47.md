# v0.1.47

This release focused on sequencing expressiveness and modulation depth.

- Added the **LFO Track** workflow with Sync/Free operation, waveform selection, range control, and dedicated shift-layer controls.
- Added support for **negative Note Gate Offset**, enabling intentional pre-grid note placement where playback timing context allows it.
- Expanded deterministic manual coverage for Note/Curve layer workflows, generator commit flows, and LFO waveform states.
