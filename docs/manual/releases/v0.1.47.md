# v0.1.47

This release adds two major sequencing features: signed Note Gate Offset timing (including predictable pre-trigger behavior) and the dedicated LFO Track with Sync and Free modes.

The same release cycle also expanded deterministic manual screenshot coverage and tightened external-clock behavior and related regression coverage.

::: {custom-style="StyrNote"}
**NOTE**

Release notes use `v0.1.47`, while some firmware builds may still display `0.1.46` on-device.
:::
